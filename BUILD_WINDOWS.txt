خطوات سريعة على Windows عبر Android Studio

1) فك الضغط عن ELYAS_LIGHT_CONTROL_ANDROID_V1_0.zip
2) افتح Android Studio
3) File -> Open -> اختر مجلد ELYAS_LIGHT_CONTROL_ANDROID_V1_0
4) انتظر تنزيل أدوات Android 35 و Gradle Sync (يتطلب إنترنت أول مرة)
5) Build -> Build Bundle(s) / APK(s) -> Build APK(s)
6) افتح: app\build\outputs\apk\debug\app-debug.apk

إذا ترغب بالبناء على GitHub دون Android Studio، راجع README_AR.txt.
