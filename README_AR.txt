ELYAS-TECH LIGHT CONTROL — Android V1.0
=========================================

تطبيق Android أصلي (Java) للتحكم بلوحة شاشة ESP32-024 العاملة بكود
ELYAS_LIGHT_SCREEN_V1_6_BT عن طريق Bluetooth Classic SPP.

المشروع جاهز للفتح في Android Studio أو البناء من GitHub Actions.
ملاحظة مهمة: هذا الأرشيف يحتوي سورس التطبيق وليس ملف APK مبنياً مسبقاً.

التوافق
-------
- هاتف Android 6.0 فأحدث مع Bluetooth Classic SPP.
- ESP32 الشاشة مرفوع عليه برنامج V1.6 Bluetooth (اسم ELYAS-LIGHT).
- ESP32 المستقبل يستمر على برنامج V1.5 بدون تغيير.
- لا يحتاج التطبيق إنترنت أو خادماً خارجياً أو قطعاً إضافية.
- لا يستخدم BLE؛ الاتصال Bluetooth Classic برقم RFCOMM SPP القياسي.

الاستخدام بعد تثبيت APK
-----------------------
1. تأكد أن الشاشة تعمل وكود V1.6 مثبت عليها.
2. افتح إعدادات Bluetooth في الهاتف واقترن بـ ELYAS-LIGHT.
3. إذا برنامج Bluetooth Terminal متصل بالشاشة، افصله أولاً؛ اتصال SPP واحد في كل مرة.
4. افتح تطبيق ELYAS LIGHT CONTROL.
5. اسمح بإذن "الأجهزة المجاورة" (Android 12 وأحدث) إذا طلب منك.
6. اضغط "اتصال بالشاشة" واختر ELYAS-LIGHT من الأجهزة المقترنة.
7. التطبيق يرسل AUTH 462913 تلقائياً ثم STATUS، وينتظر قبول رمز الدخول.
8. إذا غيّرت BT_ACCESS_CODE في كود ESP32، غيّره في التطبيق من "رمز الدخول".

الوظائف
-------
- السكن ON/OFF مستقل
- تشغيل/إطفاء الزوج 1+2، 3+4، 5+6
- تشغيل/إطفاء قوي أول 4، أو قوي الـ6
- FLASH، WAVE، AUTO SHOW، MANUAL
- سرعة 100،150،200،300،450،600،800،1000،1400،2000،3000 ms
- STRONG OFF / ALL OFF
- حالة مرآة مرسلة من شاشة ESP32، وآخر تأكيد ACK من المستقبل

منطق إشارات المستقبل:
SKIN=0x01; PAIR1=0x06; PAIR2=0x18; PAIR3=0x20;
FOUR=0x1E; SIX=0x3E

تحميل APK باستخدام GitHub Actions (بلا تثبيت Android Studio)
----------------------------------------------------------
1. فك ضغط الأرشيف كاملاً؛ لا تضع ملف ZIP نفسه في المستودع.
2. افتح GitHub وأنشئ Repository جديداً.
3. ارفع ملفات ومجلدات المشروع إلى جذر المستودع كما هي، بما فيها .github/workflows/build-apk.yml.
4. افتح تبويب Actions > Build Android APK ثم Run workflow، أو انتظر تنفيذ Push التلقائي.
5. بعد نجاح Build افتح التشغيل، ومن قسم Artifacts نزّل ELYAS_LIGHT_CONTROL_ANDROID_APK.
6. فك ضغط Artifact، تحصل على ELYAS_LIGHT_CONTROL_v1.0.apk للتثبيت على Android.
7. إذا طلب الهاتف السماح بتثبيت التطبيقات من هذا المصدر، راجع الملف واسم التطبيق ثم اسمح بالتثبيت.

بناء محلي عبر Android Studio
--------------------------
File > Open > اختر مجلد ELYAS_LIGHT_CONTROL_ANDROID_V1_0
انتظر Gradle Sync ثم Build > Build APK(s).
ملف APK يظهر في app/build/outputs/apk/debug/app-debug.apk

ملاحظات سلامة مهمة
-------------------
- عبارة ACK معناها أن المستقبل بلّغ عن ضبط المخارج، وليس قياس تيار المصابيح.
- عبارة RADIO=1 تعني أن مرسل ESP-NOW مهيأ محلياً، لا تثبت وحدها جودة الرابط.
- إذا انقطع Bluetooth أو ESP-NOW، لا يضمن هذا الإصدار أن المصابيح تنطفئ تلقائياً.
  أضف Fail-safe مستقل على ESP32 المستقبل قبل الاستخدام داخل السيارة.
- سرعات الوميض 100–200ms قد تسرّع تآكل الريليات الميكانيكية تحت الحمل.
- رمز AUTH الافتراضي ضعيف ومكشوف في سورس الشاشة؛ عدّله في ESP32 وفي التطبيق.
- التطبيق للاستخدام عند توقف السيارة، وليس أثناء القيادة.

حقائق التنفيذ
-------------
- سورس المشروع مكتوب ومطابق لأوامر كود ESP32 V1.6.
- لم يُجرَ بناء APK فعلي هنا لعدم توفر Android SDK/Gradle وأدوات الاتصال المطلوبة.
- العمل على هاتف حقيقي يحتاج اختبار Bluetooth واتصال المستقبل.
